云麓空间

一套覆盖桌面与移动端的本机应用管理器：查看、搜索、排序、卸载你设备上安装的程序与 App，所有数据本地处理，不上传任何信息。

Windows PC 版 Android 版 GitHub 仓库

项目简介

「云麓空间」是一个对标手机系统「应用管理」能力的本机工具集。它不依赖云端、不收集数据，只读取你本机已安装软件的信息，帮助你快速整理、定位与卸载。目前提供两个独立形态：

云麓空间 · PC 版

Windows 桌面端 · Python + Tkinter
  • 读取注册表三处卸载项，列出全机/用户已安装程序
  • 按名称 / 发行商实时搜索，支持分组与排序
  • 卸载走系统向导、可打开安装目录、复制卸载命令
  • 零依赖（仅 Python 标准库），已打包为 exe
PythonTkinter注册表只读exe 可直接运行
查看源码与说明 → 下载 exe（发布构建）

云麓空间 · Android 版

Android 移动端 · Kotlin + Jetpack Compose
  • 用户/系统应用分组、搜索、排序、APK 大小/版本副标题
  • 单个与批量卸载，全部走系统确认界面
  • 应用详情：权限列表、安装来源、APK 提取与分享
  • 安装/卸载后通过系统广播实时刷新列表
KotlinComposeMaterial 3HiltMVVM
查看源码与说明 → 下载 APK（V1.0.0.001 正式签名版）

功能亮点

本机优先

所有数据来自本机注册表 / PackageManager，离线可用，不联网。

隐私友好

无网络权限、不收集、不上传。卸载一律走系统界面由用户确认。

双端一致

PC 与 Android 同一套产品理念，桌面与移动无缝衔接管理体验。

开箱即用

PC 版已编译 exe；Android 版提供已签名 release APK，可直装。

透明可读

源码开放，扫描逻辑、卸载流程、权限用途全部可查。

持续演进

Android 版已进入 V3 开发线（存储可视化、清理、管控等）。

隐私与安全

无网络权限：两个版本均不申请任何网络权限，所有处理在本地完成。

只读扫描：PC 版读取注册表卸载项仅为展示，不修改系统；Android 版提取安装包只读取系统分区、不改动任何系统文件。

不静默卸载：卸载一律调用系统卸载界面，由用户在系统中确认，工具本身不做任何静默删除。
